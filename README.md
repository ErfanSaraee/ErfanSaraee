## 🏆 Featured Production Capstone Projects

Each flagship system below is engineered from scratch with **clean modular architecture, async database persistence, Docker Compose orchestration, interactive telemetry UIs, and automated `pytest` suites**:

### 1. 🛡️ [Neural Zero-Trust AI Firewall & Autonomous Red-Team Arena (`agentic-zero-trust-redteam-firewall`)](https://github.com/ErfanSaraee/agentic-zero-trust-redteam-firewall)
- **Problem Solved:** Protects tool-using AI agents against **OWASP LLM Top-10** vulnerabilities (Indirect Prompt Injection, Base64 Jailbreaks, PII Exfiltration, MCP Tool Poisoning, and Arbitrary Code Execution).
- **Architecture & Stack:** Custom **PyTorch Multi-Head Self-Attention** threat classifier, **Shannon Entropy** obfuscation analyzer, **Pinecone.io** vector threat store, formal **Python AST Static Verifier**, **CrewAI** 6-agent adversarial red-teaming, **DSPy** self-hardening prompt compiler, **FastMCP**, **A2A Protocol**, **FastAPI**, and a 2-tab **Gradio 5 & Plotly** radar arena.

### 2. 🚨 [Autonomous Multi-Agent SRE Incident Commander (`a2a-mcp-incident-commander`)](https://github.com/ErfanSaraee/a2a-mcp-incident-commander)
- **Problem Solved:** Automates root-cause analysis (RCA) and safe remediation for critical microservice outages while preventing destructive autonomous actions.
- **Architecture & Stack:** 6-node **LangGraph** state machine (`Triage Planner` $\rightarrow$ `FastMCP Forensics` $\rightarrow$ `A2A Deployment Auditor` $\rightarrow$ `RCA Synthesizer` $\rightarrow$ `DevSecOps Safety Critic` $\rightarrow$ `Human-in-the-Loop Gate`), **FastAPI**, **SQLAlchemy 2.0 (Async)**, and a **Streamlit & Plotly** command center.

### 3. 🧠 [Predictive ML-Driven LLM Router, Token FinOps & Drift Observatory (`predictive-ml-llm-gateway`)](https://github.com/ErfanSaraee/predictive-ml-llm-gateway)
- **Problem Solved:** Eliminates unnecessary frontier LLM token expenditure and latency bottlenecks by routing prompts across local (`vLLM`/`Ollama`), flash (`Gemini`/`GPT-4o-mini`), and frontier (`Claude`/`GPT-4o`) tiers in `<3ms`.
- **Architecture & Stack:** 8D sub-millisecond feature engineering, **XGBoost (`XGBClassifier` & `XGBRegressor`)**, **Scikit-Learn (`IsolationForest`)** anomaly detection, mathematical **Population Stability Index (PSI)** data drift monitoring, **FastMCP**, **FastAPI**, and **Streamlit**.

### 4. 🔍 [Enterprise Corrective Agentic RAG Backend (`enterprise-corrective-rag`)](https://github.com/ErfanSaraee/enterprise-corrective-rag)
- **Problem Solved:** Eliminates retrieval hallucinations in enterprise Q&A through self-reflective context grading, query rewriting, and hybrid lexical + semantic search.
- **Architecture & Stack:** Stateful **LangGraph** Corrective RAG (CRAG), **PostgreSQL (`pgvector`) + BM25** with **Reciprocal Rank Fusion (RRF)**, distributed background ingestion via **Celery & Redis**, **FastMCP**, **FastAPI**, and **Streamlit**.
