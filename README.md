## 🏆 Featured Production AI & MLOps Systems

Each flagship repository below is built with **modular clean architecture, asynchronous database persistence, multi-container Docker orchestration, interactive telemetry dashboards, and automated `pytest` verification suites**:

### 1. 🛡️ [Neural Zero-Trust AI Firewall & Autonomous Red-Team Arena](https://github.com/ErfanSaraee/agentic-zero-trust-redteam-firewall)
> **Multi-Layer AI Security Gateway, AST Formal Code Sandbox & Adversarial Red-Team vs. Blue-Team Platform**
- **Architecture:** Protects LLM agents against **OWASP LLM Top-10** threats using a custom **PyTorch Multi-Head Self-Attention** threat classifier, character-level **Shannon Entropy** obfuscation detection (`Base64`/`Hex`), **Pinecone.io** vector threat intelligence, and a stateless **Python AST Static Verifier** that blocks RCE and sandbox escapes prior to execution.
- **Autonomous Defense Loop:** Orchestrates 6 specialized **CrewAI** red-team personas against a **DSPy** self-hardening prompt compiler (`BootstrapFewShot` invariant synthesis), exposed via **FastMCP**, **A2A Protocol**, **FastAPI**, and a 2-tab **Gradio 5 & Plotly** radar interface.

### 2. 🚨 [Autonomous Multi-Agent SRE Incident Commander](https://github.com/ErfanSaraee/a2a-mcp-incident-commander)
> **Stateful Multi-Agent DevSecOps War-Room with FastMCP Forensics, A2A Auditing & Human-in-the-Loop Governance**
- **Architecture:** Orchestrates a 6-node **LangGraph** state machine (`Triage Planner` $\rightarrow$ `FastMCP Forensics` $\rightarrow$ `A2A Deployment Auditor` $\rightarrow$ `RCA Synthesizer` $\rightarrow$ `DevSecOps Safety Critic` $\rightarrow$ `HITL Gate`) to diagnose production `P0_CRITICAL` microservice outages in seconds.
- **Interoperability & Safety:** Combines standardized **FastMCP** telemetry/runbook tools with peer-to-peer **Agent-to-Agent (A2A)** Git diff auditing (`/.well-known/agent.json`), reflection guardrails, and an interactive **Streamlit & Plotly** command dashboard.

### 3. 🧠 [Predictive ML-Driven LLM Router, Token FinOps & Drift Observatory](https://github.com/ErfanSaraee/predictive-ml-llm-gateway)
> **Sub-3ms Prompt Complexity Router, Latency SLA Regressor & Mathematical Data Drift Engine**
- **Architecture:** Eliminates unnecessary frontier LLM expenditure by extracting an 8-dimensional syntactic/structural feature vector in `<1ms` and routing queries across local, flash, and frontier tiers using **XGBoost (`XGBClassifier` & `XGBRegressor`)** while flagging token-stuffing attacks via **Scikit-Learn (`IsolationForest`)**.
- **MLOps Governance:** Monitors live covariate shift across all engineered features using decile-bucketed **Population Stability Index (PSI)** to trigger automated model retraining alerts, paired with **FastMCP**, **FastAPI**, and a **Streamlit** FinOps observatory.

### 4. 🔍 [Enterprise Corrective Agentic RAG Backend](https://github.com/ErfanSaraee/enterprise-corrective-rag)
> **Self-Reflective Hybrid Retrieval Pipeline with Reciprocal Rank Fusion (RRF) & Distributed Ingestion**
- **Architecture:** Implements a stateful **LangGraph Corrective RAG (CRAG)** workflow that combines dense vector similarity (**PostgreSQL `pgvector`**) and lexical search (**BM25**) via **Reciprocal Rank Fusion ($k=60$)**, grading retrieved context relevance and automatically rewriting queries to prevent hallucinations.
- **Scalable Backend:** Offloads heavy document chunking and embedding workflows to distributed **Celery + Redis** worker queues, backed by **FastAPI**, **SQLAlchemy 2.0 (Async)**, and **FastMCP** server endpoints.
